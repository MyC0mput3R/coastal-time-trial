## 二、新增功能落到哪些文件（本次 3 车版）

### 2.1 两个新文件

**`src/car3data.js`（611,806 B）**
- 从你的 Blender 模型 `lotus e20.blend` 经无头导出，**原件全程只读复制，未写入**。
- 内容：`window.CR.Car3Data = {...}`，按材质颜色分组的三角面 soup，坐标 ×1000 整数存储；`meta` 记录 `scale=0.92 / tris=16131 / trisBody=10259 / 前后轮各 2936`。
- 7 个材质槽 → 黑金涂装：碳黑车身、金色尾翼/鼻锥/中脊/轮锁环、红色进气口、银轮毂、黑轮胎。
- **车头方向已修正**：该模型车头在 Blender −Y，导出用 `gx=(bx-CX)*S; gz=-(by-CY)*S`（相对首版绕竖直轴转 180°），前轮心 z=+1.230、后轮 z=−1.797；宽扁前翼在低处、高架尾翼在高处。
- 纯数据，不依赖 GLTFLoader、不联网。

**`src/car3.js`（5,118 B，129 行）**
- `CR.Car3.attach(scene)`：建独立 `root3`（名 `E20_Root`）/ `body3` / 前轮 steering pivot / 后轮 spin，挂到 `Car.roots[2]` 与 `Car.partsList[2]`。
- 复用 `car2.js` 的 `splitAxleBySide()` 思路，按顶点 x 正负把前轴拆成左右两只独立前轮 → 沿用 `Car.sync` 的前轮转向动画。
- 深色材质压低环境反射、拉高粗糙度，避免黄昏暖光把碳黑染成棕褐；`side: DoubleSide` 兼容原模型单面片。
- **不给 F1 硬塞尾灯几何**（会浮在车外穿帮），只保留 `tailMat` 材质对象供 `Car.sync` 写 `emissiveIntensity`。
- 数据缺失时 `if (!D) return` 自动跳过 → 删掉数据文件也不会让两车版崩。
